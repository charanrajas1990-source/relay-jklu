# Relay · JKLU campus marketplace

A prototype marketplace where JK Lakshmipat University students buy, rent and swap books, notes, electronics and hostel essentials.

- Single self-contained `index.html` (HTML + CSS + vanilla JS, no build step)
- Demo data is stored in the browser's localStorage
- Demo sign-in: any `@jklu.edu.in` address, code `246810`

A student project. Not an official university service.
